# SS-EXIM

SS-EXIM is a company website showcasing electrical panels, control systems, and related industrial equipment.

## Overview

This repository contains the source code for the SS-EXIM website, including product listings, services, brands, gallery, blog, and contact information.

## Structure

The project is organized into several directories: `about` for company information, `assets` for static files such as styles, scripts, and images, `blog` for articles, `brands` for brand pages, `contact` for the contact page, `gallery` for the image gallery, `products` for product listings, and `services` for the services offered.

## Products

The site features a range of electrical equipment including distribution panels, capacitor panels, busbar systems, control timers, energy meters, and more.

## Getting Started

Open `index.html` in a web browser to view the site locally.
